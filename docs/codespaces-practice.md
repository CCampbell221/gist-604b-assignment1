## Initial Observations

- What felt straightforward?

Opening the repository in Codespaces and locating the project files was straightforward. Running the Python script in the terminal was also easy once I understood where to enter the command.

- What felt unfamiliar?

The Source Control workflow was unfamiliar, particularly staging changes, committing files, and synchronizing changes with GitHub.

- Where is the Source Control panel located?

The Source Control panel is located on the left Activity Bar in Codespaces. It can be opened by clicking the branching icon.

## Understanding Git Workflow

The local workspace in Codespaces is where I edit files, run Python scripts, and test changes before sharing them. The remote repository on GitHub.com stores the project's shared version and commit history. After making changes in Codespaces, I can stage, commit, and push them to update the remote repository.
