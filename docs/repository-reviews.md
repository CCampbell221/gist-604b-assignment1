## 1. QGIS

**Repository:** https://github.com/qgis/QGIS

QGIS is an open-source geographic information system used for spatial analysis, data management, and cartographic design. Its repository contains source code, documentation, and resources supporting development across different operating systems.

The project has a large development community and supports contributions through GitHub. Its documentation and organizational structure help users understand how the software is developed and maintained.

## 2. GeoPandas

**Repository:** https://github.com/geopandas/geopandas

GeoPandas is a Python library that extends pandas to support geographic data. It provides GeoDataFrame and GeoSeries objects for managing spatial information and performing geometric operations.

I found GeoPandas particularly relevant because it connects Python programming with GIS analysis. The README provides installation instructions, examples, and links to documentation, making the project accessible to new users.

## 3. PostGIS

**Repository:** https://github.com/postgis/postgis

PostGIS is an open-source spatial database extension for PostgreSQL. It supports storing, querying, and analyzing geographic information within a relational database.

The repository includes source code and documentation related to spatial database functionality. PostGIS demonstrates how open-source tools support the management of large geographic datasets beyond desktop GIS applications.

## 4. Leaflet

**Repository:** https://github.com/Leaflet/Leaflet

Leaflet is an open-source JavaScript library used to develop interactive web maps. It is designed to be lightweight and works across desktop and mobile browsers.

Its repository includes source code, documentation, examples, and contribution guidelines. Leaflet is especially relevant to web GIS because it allows developers to build interactive maps without relying on proprietary mapping software.

## Reflection

Reviewing these repositories helped me understand how open-source GIS projects are organized and maintained through GitHub. Each project supports a different part of geospatial technology, including desktop mapping, Python analysis, spatial databases, and web mapping. I noticed that clear documentation, issue tracking, and contribution guidelines are important for supporting collaboration among developers and users. Exploring these projects also showed me how GitHub can support GIS workflows beyond simply storing code.
